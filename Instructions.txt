Project Status Summary

Setup: Windows laptop, i3-7020U, 8GB RAM, no dedicated GPU. Python 3.11 (via py -3.11), Ollama with llama3.2:3b, Node.js installed. Project folder: C:\Users\dell\Desktop\AI-Avatar-Project\ with brain/ and avatar/ subfolders.

Working features:

Voice chat in English, Hindi, Kannada (3-pass Whisper detection + script correction)
Short, sweet, personality-driven replies (1 sentence, num_predict: 25)
Fact-checking via DuckDuckGo search (ddgs package) before factual answers
Persistent memory across sessions (SQLite via memory.py) — remembers facts about the user
3D VRM avatar (Three.js) with: relaxed idle arm pose, natural continuous sway (not random gestures), word-synced lip movement, emotion-reactive smiling, click-to-wink, custom background image, zoomed face-forward camera framing, intro video before avatar appears
Says goodbye out loud when "stop"/"quit" is said

Parked for later: Camera-based wave detection and avatar waving back (camera.py was drafted but caused issues — currently removed from server.py). Double-tap-to-wave was also removed after rigging issues (arm rotation didn't match this avatar's skeleton).

Not yet built: Wake word ("wake up" to activate), "let's go" to play a custom video on command.
